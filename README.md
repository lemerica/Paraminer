Paraminer - инструмент для динамического анализа параметров и автоматического обнаружения скрытых уязвимостей в веб-приложениях. Софт сочетает в себе параллельный стриминг данных, поведенческие оракулы и дом-диффинг для выявления скрытых параметров, уязвимостей к инъекциям и логических ошибок.

Основные возможности:

1) Параллельный streaming-pipeline. Обработка сетевых запросов и ответов в реальном времени без блокировки основного потока.

2) Поведенческие оракулы. Автоматический анализ изменений в поведении приложения при манипуляции параметрами.

3) Интеграция с DOM-диффингом. Точечное сравнение структуры документов для фиксации минимальных изменений в веб-интерфейсе.

4) Статистические тесты. Проверка значимости аномалий в ответах сервера для минимизации ложных срабатываний.

# Требования
Для работы утилиты необходим Python версии 3.10 или выше. Зависимости указаны в файле requirements.txt.

# Установка:
Склонируйте репозиторий:

git clone https://github.com/your-repository/paraminer.git
cd paraminer


# Базовый запуск
Для сканирования целевого URL с настройками по умолчанию выполните команду:

# python paraminer.py --url https://example.com/target

# Дополнительные параметры:
Вы можете настроить процесс анализа с помощью флагов в терминале:

--threads [число] — устанавливает количество потоков для параллельной обработки.

--oracle [тип] — выбирает конкретный поведенческий оракул (например, diff, time, status).

--output [путь] — сохраняет результаты работы в файл.

Пример команды с расширенными настройками:


# python paraminer.py --url https://example.com/target --threads 10 --oracle diff --output report.json

Разработка:
Код компонента paraminer.py версии 0.6 разделен на логические блоки:

1) Инициализация сетевого соединения и пайплайна.

2) Блок статистического анализа ответов.

3) Модуль сравнения DOM-деревьев.
